Campfire-1

Sherlock Scenario

夏洛克剧本

Alonzo Spotted Weird files on his computer and informed the newly assembled SOC Team. Assessing the situation it is believed a Kerberoasting attack may have occurred in the network. It is your job to confirm the findings by analyzing the provided evidence.

阿隆佐在他的电脑上发现了奇怪的文件，并通知了新组建的SOC团队。根据评估情况，我们认为网络中可能发生了 Kerberoasting 攻击。你的任务是通过分析所提供的证据来确认这一结论。

You are provided with:

您将获得：

1- Security Logs from the Domain Controller

1- 域控制器的安全日志

2- PowerShell-Operational Logs from the affected workstation

2- 受影响工作站的 PowerShell 操作日志

3- Prefetch Files from the affected workstation

3- 从受影响的工作站预取文件

对域、Kerberos了解不多，补充一些基础知识：

Kerberoasting Attack.

是 AD 域内一种低权限即可发起、离线爆破的凭证窃取技术，属于滥用 Kerberos 协议正常逻辑。

大致攻击步骤：

  1. 拿到域用户身份，请求 TGT 票据
  2. 通过 TGT 查询 AD，枚举域内带 SPN 的服务账号
  3. 使用 TGT 向 KDC 发送 TGS_REQ，请求该 SPN 的服务票据 TGS
  4. 导出 TGS 票据，提取可爆破的 Hash
  5. 离线爆破 Hash

SPN（Service Principal Name）：服务在域内的身份标识，格式为 服务类/主机名:端口，例如 MSSQLSVC/sql01.corp.local:1433。

KDC（Key Distribution Center 密钥分发中心）：Kerberos 协议的核心服务，直接跑在域控制器 DC 上。

TGT：用户的票据授予票据，向 KDC 申请 TGS 用。

TGS：服务票据，用来访问对应 SPN 的服务。

AD 域 （Active Directory 活动目录）

AD 是微软 Windows 域环境的核心服务，一般部署在 Windows Server（域控DC）上，本质是一个集中式账号、权限、资源管理数据库。

Kerberos.

是 AD 域默认的身份认证协议，基于票据 Ticket 的认证体系，用来在域环境里，让用户/机器不用反复输密码，去访问域内各种服务。

这次解题参考的题解在：https://0xdf.gitlab.io/2024/06/24/htb-sherlock-campfire-1.html

Task 1

Analyzing Domain Controller Security Logs, can you confirm the UTC date & time when the kerberoasting activity occurred?

通过分析域控制器安全日志，您能否确认 kerberoasting 活动发生的 UTC 日期和时间？

Event ID 4769 = 请求 TGS（TGS_REQ）

Event ID 4768 = 请求 TGT （AS_REQ）

4769 事件是 Kerberosating 攻击的标志。

而只有 TicketEncryptionType 为 0x17 的代表 RC4-HMAC 加密的 Kerberos TGS 票据，只有这种才支持 Kerberoasting 离线爆破。

这个事件的记录时间为 2024/5/21 11:18:09

因为中国标准时间是 UTC+8，所以发生的 UTC 时间为 ：2024-05-21 03:18:09

答案：2024-05-21 03:18:09

Task 2

What is the Service Name that was targeted?

被攻击的服务名称是什么？

ServiceName 为 MSSQLService。

答案：MSSQLService

Task 3

It is really important to identify the Workstation from which this activity occurred. What is the IP Address of the workstation?

确定发生此活动的工作站至关重要。该工作站的 IP 地址是什么？

IpAddress 为 ::ffff:172.17.79.129。

答案：172.17.79.129

Task 4

Now that we have identified the workstation, a triage including PowerShell logs and Prefetch files are provided to you for some deeper insights so we can understand how this activity occurred on the endpoint. What is the name of the file used to Enumerate Active directory objects and possibly find Kerberoastable accounts in the network?

现在我们已经确定了工作站，我们将向您提供包含 PowerShell 日志和预取文件的分类信息，以便您更深入地了解此活动是如何在端点上发生的。用于枚举 Active Directory 对象并可能在网络中查找 Kerberoastable 帐户的文件名是什么？

Event ID 4104 = Script Block Logging（脚本块日志）。

用于 PowerShell 在编译脚本块时，记录脚本原文。

按时间顺序查看 4104，第一条命令是 powershell -ep bypass，作用为绕过本机 PowerShell 执行策略，允许运行脚本 .ps1。

然后后面几条 4104 执行的都是同一个文件 C:\Users\alonzo.spire\Downloads\powerview.ps1

答案：powerview.ps1

Task 5

When was this script executed? (UTC)

该脚本何时执行？（UTC）

答案：2024-05-21 03:16:32

Task 6

What is the full path of the tool used to perform the actual kerberoasting attack?

执行实际 Kerberoasting 攻击的工具的完整路径是什么？

根据最后一条 4104 Event，可知脚本扫描结束是 11:17，所以查看这个时间之后的文件。

文件去 prefetch 文件夹下看。这个文件夹取自 C:\Windows\Prefetch，是 Windows 的系统性能加速机制，它的工作原理是：Windows 为了加快程序下次启动速度，当一个 EXE 程序运行后，系统字典生成一份 .pf 文件，记录这个 exe 的一些基本信息和运行信息。

而 RUBEUS.EXE 是知名域渗透工具，专用于 Kerberoast 和票据操作。

由于 .pf 是二进制 SCCA 格式，所以不能记事本、powershell、cmd 这些直接解码其中的信息。

可以使用 PECmd.exe，是一种专门解析二进制 .pf 的蓝队工具。

下载链接：https://ericzimmerman.github.io/，我下载的是 .net 4 版本。
