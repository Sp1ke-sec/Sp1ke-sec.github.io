LDAP Lightweight Directory Access Protocol，轻量目录访问协议

是一套用来查询、读取目录信息的协议。

这里的目录一般用于存身份信息，如用户、账号、密码、组等等。

立足点

访问 http://10.129.77.52，会被重定向到 443 端口的 https://10.129.77.52；又会被重定向为 management.htb。

在 hosts 中添加一条规则，即可顺利访问：

1

echo "10.129.77.52 *.management.htb" >> /etc/hosts

一个静态页面，本身没有什么功能点。

点击右上角的 Client login，会跳转到 sso.management.htb，把这条规则也加入 /etc/hosts。

可知版本为 v16.0.5，存在 CVE-2026-33439 Pre-Auth RCE。

在 16.0.6 版本之前，OpenIdentityPlatform OpenAM 存在通过不安全的 Java 反序列化 jato.clientSession HTTP 参数进行无需身份验证远程代码执行 (RCE) 的漏洞。未经身份验证的攻击者可以通过发送精心构造的序列化 Java 对象，在服务器上执行任意命令。作为 jato.clientSession GET/POST 参数，向任何 JSP 包含 <jato:form> 标签的 JATO ViewBean 端点发送请求（例如，密码重置页面）。

密码是经过加密的，GLPI 10.x 使用 libsodium 的 XChaCha20-Poly1305（一种现代认证加密算法）对这类密钥进行加密。加密后的数据块结构如下：

1

[ 24-byte nonce ] + [ ciphertext + authentication tag ]
  • nonce 是每次加密时使用一次的随机值（不是秘密的，与数据一起存储）。
  • 用于加密/解密的实际密钥单独存储，位于：/opt/glpi/config/glpicrypt.key

而这种加密是可逆的，所以要解密：将 blob 分成 nonce + 密文，然后使用密钥运行 libsodium 的解密函数。

解密脚本：

1
2
3
4

php -r "
\$key = file_get_contents('/opt/glpi/config/glpicrypt.key');
\$ciphertext = base64_decode('avrqW65aZWKzLAKWhPxZGn1eLj3yYAnwUp08mEazsJUWfI5cqbaP6vM12w0p/ykpmyO3Pw==');
\$nonce = substr(\$ciphertext, 0, SODIUM_CRYPTO_AEAD_XCHACHA20POLY1305_IETF_NPUBBYTES);
\$data  = substr(\$ciphertext, SODIUM_CRYPTO_AEAD_XCHACHA20POLY1305_IETF_NPUBBYTES);
\$plain = sodium_crypto_aead_xchacha20poly1305_ietf_decrypt(\$data, \$nonce, \$nonce, \$key);
echo \$plain . PHP_EOL;
"

rdiff-backup 是增量备份工具，--server 以服务端模式运行，--restrict-path /opt/backup 强制限定 rdiff-backup 只能访问这个目录，--restrict-mode read-only 客户端只能读取里面的文件；* 占位参数。

存在危险的就是最后的 * 参数。因为这允许我们在命令的固定部分之后添加任何额外参数。

rdiff-backup 从左到右解析参数，如果同一个选项给出了两次，则最后一个选项生效。

所以，如果我们能输入--restrict-path /，它将完全覆盖原始的 /opt/backup 限制，从而使 root 拥有的 rdiff-backup --server 进程能够访问整个文件系统。

但是我们不能在原本的命令后面直接插入 --restrict-path /，因为这是固定命令，我们客户端传的参数会被丢弃。

诀窍在于 rdiff-backup 自身的 --remote-schema 选项，该选项允许客户端自定义用于生成服务器进程的命令，使用 %s 作为目标位置主机名部分的占位符。

rdiff-backup 将位置信息解析为 hostname::path 格式。因此，位置信息如下：

1

/::/root

解析结果为 hostname = / 和 path = /root。当客户端构建服务器命令时，它会将 %s 替换为该主机名（即 /）。

1
2
3

rdiff-backup \
  --remote-schema "sudo /usr/bin/rdiff-backup --server --restrict-path /opt/backup --restrict-mode read-only --restrict-path %s" \
  backup /::/root /tmp/root_backup
