Redeemer

About: Redeemer is a very easy Linux machine which explores the enumeration and exploitation of a Redis database server while showcasing the redis-cli command line utility and basic commands to interact with the Redis service.

介绍：Redeemer 是一个非常简单的 Linux 机器，它探索了 Redis 数据库服务器的枚举和利用，同时展示了 redis-cli 命令行实用程序和与 Redis 服务交互的基本命令。

Task 3

What type of database is Redis? Choose from the following options: (i) In-memory Database, (ii) Traditional Database

Redis 是什么类型的数据库？请从以下选项中选择：（i）内存数据库，（ii）传统数据库

Redis 是开源的、基于内存的键值（Key-Value）数据库，数据主要存放在内存中，同时支持持久化落盘。传统数据库一般指 MySQL、PostgreSQL 这类磁盘型关系库。

答案：In-memory Database

Task 7

What is the version of the Redis server being used on the target machine?

目标机器上使用的 Redis 服务器版本是什么？

根据 info 命令回显中的 redis_version:5.0.7 可知 Redis 服务器版本。

答案：5.0.7

Task 8

Which command is used to select the desired database in Redis?

在 Redis 中，使用哪个命令来选择所需的数据库？

在 info 命令的回显中，最后一块 # Keyspace 会列出有数据的 db（即数据库）。

这里只有一个数据库 db0:keys=4,expires=0,avg_ttl=0。

  • keys=4 代表库里一共 4 个 key
  • expires=0 设置了过期时间的 key 的数量是 0
  • avg_ttl=0 所有带过期 key 的平均剩余存活时间（单位毫秒）
1
2
3
4
5

10.129.136.187:6379> info keyspace
# Keyspace
db0:keys=4,expires=0,avg_ttl=0
10.129.136.187:6379> select 0
OK

答案：select

Task 9

How many keys are present inside the database with index 0?

数据库中索引为 0 的键有多少个？

因为 db0:keys=4,expires=0,avg_ttl=0，意思就是索引为 0 的数据库里有四个 key。

所以这四个键都是索引为 0。

答案：4
