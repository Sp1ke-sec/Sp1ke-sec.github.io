Oopsie

About: Oopsie is a very easy Linux machine that highlights the impact of information disclosure and broken access control in web applications. Website enumeration reveals a guest login with manipulatable cookies and user IDs allowing escalation to an admin role and access to a file upload feature. A PHP reverse shell is then uploaded to gain an initial foothold. Further enumeration exposes hardcoded credentials enabling lateral movement to another user. Finally, privilege escalation is achieved by abusing a misconfigured SUID binary through PATH hijacking.

介绍：Oopsie 是一个非常简单的 Linux 机器，它突出了 Web 应用程序中信息泄露和访问控制失效的影响。网站枚举显示，访客登录存在可操纵 cookie 和用户 ID 的漏洞，从而可以升级到管理员角色并访问文件上传功能。然后上传一个 PHP 反向 shell 来获得初始立足点。进一步枚举会暴露硬编码的凭据，从而允许横向移动到其他用户。最后，通过 PATH 劫持滥用配置错误的 SUID 二进制文件来实现权限提升。

Task 3

What can be modified in Firefox to get access to the upload page?

如何在 Firefox 中进行修改才能访问上传页面？

不知道管理员账密，先通过 Guest 用户登录。

访问 /cdn-cgi/login/admin.php?content=uploads 尝试进入文件上传页面。

但实际上禁止访问，回显 This action require super admin rights.。

也就是说我们的权限不够，那么服务器是怎么判断我们的权限的呢？查看请求头中的 Cookie 就能得到答案，我们的权限 role=guest。

给 role 修改为 admin 试试。

发现还是不行，那就说明还有对 user=2233 的校验，现在想办法拿到 Admin 的 user id。

访问 /cdn-cgi/login/admin.php?content=accounts&id=2 会回显 guest 用户的信息。

如果我们把 URL 修改为 /cdn-cgi/login/admin.php?content=accounts&id=1，就会回显 admin 的信息。

拿得到的 Access ID 修改 Cookie，就可以访问文件上传页面了。

答案：cookie

我们看到属主执行位是 s，也就是 SUID。

Submit Root Flag

Submit the flag located in root’s home directory.

提交位于 root 用户主目录中的 flag。

PATH 劫持。 PATH 是 Linux 的环境变量，系统在执行一条不带绝对路径的命令时，会按照 PATH 里冒号分隔的目录顺序依次查找可执行文件，找到第一个同名程序就执行它。 PATH 劫持（PATH Hijacking）本质：把我们可控的目录放到 PATH 靠前位置，放一个和目标命令同名的恶意程序，用户 / 脚本调用这个命令时，优先跑我们的恶意文件。
