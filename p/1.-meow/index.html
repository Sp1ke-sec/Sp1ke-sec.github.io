└─# nmap -Pn -p- --min-rate 5000 10.129.74.170 
Starting Nmap 7.99 ( https://nmap.org ) at 2026-10-26 03:24 -0400
Nmap scan report for 10.129.74.170 (10.129.74.170)

PORT   STATE SERVICE
23/tcp open  telnet

Telnet 是一个古老的远程登录服务，默认端口 23/TCP。

通过 telnet，我们可以远程连接一台机器，拿到它的命令行终端。

由于 Telnet 所有的传输都是明文，所以已不再用于当前的生产环境，取而代之的是加密传输的 SSH 服务。

答案：telnet

通过 telnet 10.129.74.170 连接 Telnet 服务，输入 root 即可免密登录。

这个 root 是通过猜测得出的，因为 Linux 系统的默认超级账号就是 root。

也可以使用 hydra 工具进行爆破：

1
2
3
4
5

hydra -L /usr/share/wordlists/seclists/Usernames/cirt-default-usernames.txt -e n telnet://10.129.74.170 -vV

-L 指定用户名列表
-e n 尝试空密码
-vV 打印详细尝试日志

但是这里由于题目的 telnet 服务很卡，导致爆破特别慢，所以简单爆破了一会就放弃了。

答案：root
