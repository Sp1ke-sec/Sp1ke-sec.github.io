Sequel

About: Sequel is a very easy Linux machine that introduces a vulnerable MySQL service misconfigured to allow access without a password. The machine showcases how to enumerate and interact with the database through SQL queries to extract critical information.

介绍：Sequel 是一个非常简单的 Linux 机器，它引入了一个存在漏洞的 MySQL 服务，该服务配置错误，允许在没有密码的情况下访问。该机器展示了如何通过 SQL 查询枚举数据库并与之交互，以提取关键信息。

靶机 IP：10.129.89.86

Enter password: 
ERROR 2026 (HY000): TLS/SSL error: SSL is required, but the server does not support it

┌──(root㉿kali)-[~]
└─# mysql -h 10.129.89.86 -u root -p --skip-ssl
Enter password: 
Welcome to the MariaDB monitor.  Commands end with ; or \g.
Your MariaDB connection id is 130
Server version: 10.3.27-MariaDB-0+deb10u1 Debian 10

Copyright (c) 2000, 2018, Oracle, MariaDB Corporation Ab and others.

MariaDB [(none)]>

-h 指定 IP，-u 指定用户名，-p 指定密码。

由于新版 kali 中的 mysql 客户端默认走 SSL，但是靶机没有开启 SSL，所以协商失败。

因此添加 --skip-ssl 关闭 SSL。

答案：root
