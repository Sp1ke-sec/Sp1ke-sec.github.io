Web

Web 没有什么功能，就是一个部署文档。

还有一句 Do not commit a local .env file.

提示很明显了，就是要在 git 里找泄露的 .env 文件，这个文件一般存一些环境变量、密钥之类的。

发现 svc-bkp 用户的密码是 *。

可用 CVE-2026-123158： OpenSSH + musl libc、没开 PAM 的环境下，给 /etc/shadow 里标记为 *（禁止密码登录）的用户，提交257~1024 字节任意超长密码，直接绕过 SSH 密码认证登录。
