DFIR 第 1 台

A Sherlock can fit into one of these categories:

  • DFIR
  • SOC
  • Malware Analysis
  • Threat Hunting
  • Threat Intelligence
  • Cloud

一个 Sherlock 可以归入以下类别之一：

  • 数字取证与事件响应 (DFIR)
  • 安全运营中心 (SOC)
  • 恶意软件分析
  • 威胁狩猎
  • 威胁情报
  • 云

How to Play Sherlocks

To play a Sherlock, you need to :

要进行一个 Sherlock，你需要：

  1. Download the Investigation Package: Download the specific investigation package for your chosen scenario. This is a downloadable zip file containing the data you need to logically piece together the evidence. The password to extract this file is always “hacktheblue”. 下载调查资料包：下载适用于您所选场景的特定调查资料包。这是一个可下载的压缩文件，其中包含您逻辑地拼凑证据所需的数据。解压此文件的密码始终为“hacktheblue”。
  2. Review the Contents: Thoroughly review the downloaded data in a secure, isolated environment. 检查内容：在安全、隔离的环境中彻底检查下载的数据。
  3. Answer the Tasks: You will be presented with a series of mandatory questions related to the scenario. Submit your answers directly on the HackTheBox platform to solve the investigation. 完成任务：您将看到一系列与场景相关的必答题。请直接在 HackTheBox 平台上提交答案以完成调查。

Please be aware that Sherlocks may include real malware that requires careful handling.

请注意，Sherlocks 可能包含真正的恶意软件，需要谨慎处理。

  1. Mandatory Readme File: Each downloadable artifact will include a readme file that you must read thoroughly before proceeding with the exercise. This file contains vital instructions and precautions to ensure your safety throughout the experience. 强制性 Readme 文件：每个可下载的资料都将包含一个 Readme 文件，您必须在进行练习之前仔细阅读该文件。本文件包含确保您在整个体验过程中安全的重要说明和注意事项。
  2. Explicit Warning: We want to emphasize that the files you download may contain malicious code. We strongly encourage you to employ a Virtual Machine (VM) when interacting with these artifacts. Using a VM provides an additional layer of protection for your system, preventing any potential harm. 明确警告：我们特此强调，您下载的文件可能包含恶意代码。我们强烈建议您在使用这些文件时使用虚拟机 (VM)。使用虚拟机可以为您的系统提供额外的保护层，防止任何潜在的损害。
