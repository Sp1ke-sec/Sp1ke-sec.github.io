Unit42

Sherlock Scenario

夏洛克剧本

In this Sherlock, you will familiarize yourself with Sysmon logs and various useful EventIDs for identifying and analyzing malicious activities on a Windows system. Palo Alto’s Unit42 recently conducted research on an UltraVNC campaign, wherein attackers utilized a backdoored version of UltraVNC to maintain access to systems. This lab is inspired by that campaign and guides participants through the initial access stage of the campaign.

在本教程中，您将熟悉 Sysmon 日志和各种有用的 EventID，以便识别和分析 Windows 系统上的恶意活动。Palo Alto Networks 的 Unit42 最近对 UltraVNC 攻击活动进行了研究，攻击者利用 UltraVNC 的后门版本来维持对系统的访问权限。这个实验室的灵感来源于那次活动，它将指导参与者完成活动的初始访问阶段。

To answer the questions in this lab, you will only need the Event Viewer, with VirusTotal as an optional supplement. Below are some important Sysmon Event IDs that can be utilized in your analysis:

要回答本实验中的问题，您只需要事件查看器，VirusTotal 可作为可选的补充工具。以下是一些重要的 Sysmon 事件 ID，您可以在分析中使用：

  • Event ID 1: Process Creation/Execution. Includes process path, parent process path, and command-line arguments.

    事件 ID 1：进程创建/执行。包括进程路径、父进程路径和命令行参数。

  • Event ID 2: File Creation Time Changed. Includes the file making the change, the file to which the change is being made, tampered timestamp, and original timestamp.

    事件 ID 2：文件创建时间已更改。包括进行更改的文件、被更改的文件、篡改的时间戳和原始时间戳。

  • Event ID 3: Network Connection. Includes the process making the connection, destination IP Address, and port.

    事件 ID 3：网络连接。包括建立连接的进程、目标 IP 地址和端口。

  • Event ID 5: Process Termination. Includes the name of the process that was killed or terminated itself.

    事件 ID 5：进程终止。包括被终止或自行终止的进程名称。

  • Event ID 11: File Created. Includes the process creating the file, the file being created, and its full path.

    事件 ID 11：文件已创建。包括创建文件的进程、正在创建的文件及其完整路径。

  • Event ID 22: DNS Query. Includes the process querying the domain, the target domain name, and the IP Addresses they resolve to.

    事件 ID 22：DNS 查询。包括查询域的过程、目标域名及其解析到的 IP 地址。

.evtx 是 Windows Vista+ 的二进制事件日志文件（旧版是 .evt），存放登录、进程、服务、Sysmon、安全审计记录，Windows 默认路径： C:\Windows\System32\winevt\Logs\。

对于 .evtx 文件，我们可以在 Windows 上使用时间查看器 Event Viewer 直接打开，也可以在 Powershell 中通过原生 Get-WinEvent 进行分析。

Task 1

How many Event logs are there with Event ID 11?

事件 ID 为 11 的事件日志有多少条？

使用 Event Viewer，只需在右侧筛选当前日志，只看 ID 为 11 的事件。

使用 Powershell。

1
2

PS F:\kali_share\unit42> (Get-WinEvent -Path .\Microsoft-Windows-Sysmon-Operational.evtx | Where-Object { $_.Id -eq 11 }).count
56

Get-WinEvent -Path .\xxx.evtx 读取事件日志。

Where-Object { $_.Id -eq 11 } 筛选 ID 等于 11 的事件。$_ 代表事件、.Id 代表 Event ID、-eq 代表等于。

(...).count 计数。

答案：56

Task 2

Whenever a process is created in memory, an event with Event ID 1 is recorded with details such as command line, hashes, process path, parent process path, etc. This information is very useful for an analyst because it allows us to see all programs executed on a system, which means we can spot any malicious processes being executed. What is the malicious process that infected the victim’s system?

每当在内存中创建一个进程时，都会记录一个事件 ID 为 1 的事件，其中包含命令行、哈希值、进程路径、父进程路径等详细信息。这些信息对分析人员非常有用，因为它使我们能够看到系统上执行的所有程序，这意味着我们可以发现任何正在执行的恶意进程。那么，究竟是什么恶意进程感染了受害者的系统呢？

Task 3

Which Cloud drive was used to distribute the malware?

恶意软件是通过哪个云盘传播的？

通过云盘下载，会通过 DNS 请求查询云盘对应域名的 IP，所以筛选 ID 22，即 DNS Query。

只用看前两条，因为第三条时间已经是在恶意文件执行之后。

第一条请求的是 uc2f030016253ec53f4953980a4e.dl.dropboxusercontent.com。

第二条请求的是 d.dropbox.com。

Dropbox 是国外的云盘

答案：dropbox

Task 4

For many of the files it wrote to disk, the initial malicious file used a defense evasion technique called Time Stomping, where the file creation date is changed to make it appear older and blend in with other files. What was the timestamp changed to for the PDF file?

对于它写入磁盘的许多文件，初始恶意文件使用了一种称为时间篡改的防御规避技术，该技术会更改文件的创建日期，使其看起来更旧，并与其他文件混为一谈。PDF文件的时间戳被更改成了什么？

Event ID 2 = File Creation Time Changed（文件创建时间被修改）。

筛选 ID=2，找到对应的 PDF 文件。

CreationUtcTime 就是修改后的时间。

答案：2024-01-14 08:10:06

Task 5

The malicious file dropped a few files on disk. Where was “once.cmd” created on disk? Please answer with the full path along with the filename.

恶意文件在磁盘上留下了一些文件。“once.cmd”文件创建在磁盘的哪个位置？请提供完整路径和文件名。

Event ID 11 = File Created（文件已创建）。

筛选 ID=11，找到对应的 once.cmd 文件。

答案：C:\Users\CyberJunkie\AppData\Roaming\Photo and Fax Vn\Photo and vn 1.1.2\install\F97891C\WindowsVolume\Games\once.cmd

Task 6

The malicious file attempted to reach a dummy domain, most likely to check the internet connection status. What domain name did it try to connect to?

恶意文件试图连接到一个虚假域名，很可能是为了检查网络连接状态。它尝试连接的域名是什么？

筛选 ID=22，找到对应的域名。

答案：www.example.com

Task 7

Which IP address did the malicious process try to reach out to?

恶意进程尝试连接哪个IP地址？

Event ID 3 = NetworkConnect（网络连接）。

筛选 ID=3，找到对应的 IP 地址。

答案：93.184.216.34

Task 8

The malicious process terminated itself after infecting the PC with a backdoored variant of UltraVNC. When did the process terminate itself?

恶意进程在用植入后门的 UltraVNC 变种程序感染电脑后自行终止。该进程何时自行终止的？

Event ID 5 = Process Termination（进程终止）。

筛选 ID=5，找到对应事件的时间。

答案：2024-02-14 03:41:58
