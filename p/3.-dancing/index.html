Dancing

About: Dancing is a very easy Windows machine which introduces the Server Message Block (SMB) protocol, its enumeration and its exploitation when misconfigured to allow access without a password.

介绍: Dancing 是一款非常简单的 Windows 机器，它介绍了服务器消息块 (SMB) 协议、其枚举以及在配置错误时如何利用该协议来允许无需密码即可访问。

靶机 IP: 10.129.1.12

Task 1

What does the 3-letter acronym SMB stand for?

SMB这三个字母的缩写代表什么？

SMB（Server Message Block，服务器消息块），Windows 原生的 C/S 模式文件共享协议。

答案：Server Message Block

Task 2

What port does SMB use to operate at?

SMB协议使用哪个端口运行？

SMB 协议默认端口 445。

答案：445

Task 4

What is the ‘flag’ or ‘switch’ that we can use with the smbclient utility to ’list’ the available SMB shares on Dancing?

┌──(root㉿kali)-[~/HTB/Dancing]
└─# smbclient -L //10.129.1.12 -N

        Sharename       Type      Comment
        ---------       ----      -------
        ADMIN$          Disk      Remote Admin
        C$              Disk      Default share
        IPC$            IPC       Remote IPC
        WorkShares      Disk      
Reconnecting with SMB1 for workgroup listing.
do_connect: Connection to 10.129.1.12 failed (Error NT_STATUS_RESOURCE_NAME_NOT_FOUND)
Unable to connect with SMB1 -- no workgroup available

-L 枚举可用的 SMB 共享；-N 直接使用空密码尝试连接。

枚举结果有 Sharename、Type、Comment 三列，分别是共享名、共享类型、共享注释。

  • Sharename：
    • ADMIN$ / C$ 是 Windows 内置管理共享，默认权限严格，匿名无法访问。
    • IPC$ 用于进程间通信。
    • WorkShares 是自定义业务共享。
  • Type：
    • Disk 磁盘共享（文件夹共享）。
    • IPC IPC 管道共享，用于 RPC 通信。
  • Comment：
    • 注释，可以为空。

答案：-L
