Responder

About: Responder is a very easy Windows machine that focuses on exploring the File Inclusion vulnerability on a web application and how this can be leveraged to collect the NetNTLMv2 challenge of the user that is running the web server. The machine showcases the Responder utility and the hash cracking tool John The Ripper to obtain a cleartext password from an NTLM hash. Finally, the Evil-WinRM tool can be used to get a terminal on the machine using the acquired credentials.

介绍：Responder 是一款非常简单的 Windows 机器，专注于探索 Web 应用程序上的文件包含漏洞，以及如何利用该漏洞收集运行 Web 服务器的用户的 NetNTLMv2 挑战。该机器展示了 Responder 实用程序和哈希破解工具 John The Ripper，可以从 NTLM 哈希中获取明文密码。最后，可以使用 Evil-WinRM 工具，通过获取的凭据在机器上获取终端。

靶机 IP：10.129.90.34

When visiting the web service using the IP address, what is the domain that we are being redirected to?

使用 IP 地址访问网络服务时，我们会被重定向到哪个域名？

重定向到 unika.htb 域名。

管理员身份打开 cmd，输入 notepad C:\Windows\System32\drivers\etc\hosts。

在文件中加入一行 10.129.90.34 unika.htb，保存之后刷新 DNS ipconfig /flushdns。

答案：unika.htb

Task 6

What does NTLM stand for?

NTLM 代表什么？

NTLM 是微软的身份认证协议，用于验证 Windows 客户端访问服务时的身份，不传输明文密码。

NTLM 是一个质询应答协议，共三条核心消息：

  1. Negotiate 协商消息（客户端 → 服务端）：客户端告诉服务器，我支持 NTLM 版本、加密能力、域 / 主机名，发起认证协商。
  2. Challenge 质询消息（服务端 → 客户端）：服务器生成一个随机挑战串（Challenge），返回给客户端；同时告诉客户端协商好的安全参数。
  3. Authenticate 认证消息（客户端 → 服务端）：客户端取出 Challenge，用本机保存的NT 哈希，按照 NTLMv1/v2 算法算出 Response（应答）； 把用户名、域、这个应答一起打包发给服务器。
  4. 校验阶段：服务器本地 SAM 库取出该用户 NT 哈希，拿同一个 Challenge 自己计算应答，两边对比，一致则认证成功。

答案：New Technology LAN Manager
