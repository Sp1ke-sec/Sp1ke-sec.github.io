可以看到 type === 'reset_token' 这个字段。

我们通过 # 截断来将 type=email 替换为 type=reset_token。

# 在 URL 规范里是片段标识符，浏览器/客户端会把 # 后面所有内容不发给服务器，只留在浏览器本地解析。

因此我们可以利用 # 去截断后面的参数。

输入：admin&type=reset_token#

然后通过返回的 result 进入重置密码的界面： /change_pass?reset_token=f31ed6fc80cb32f2812e843ccf9c2003

tar 也分很多种，这里用的是 BusyBox tar。

GNU tar 是 Ubuntu/CentOS 默认的完整版 tar，可以使用 --checkpoint 直接拿到 SHELL。

BusyBox 是一个“单二进制集成很多小命令”的工具集，里面自带一个简化版的 tar，没有 --checkpoint。

这里我们可以看到 /bin/tar 其实是指向 /bin/busybox 的一个软链接，即它是 BusyBox tar。

遇到这种 tar，可以使用 create + stdout 的方式，通过其 root 权限读取受保护的文件，实现任意文件读取的效果。
