介绍：Appointment 是一个非常简单的 Linux 机器，它展示了针对启用 SQL 数据库的 Web 应用程序的 SQL 注入入门技术。

Task 11

If user input is not handled carefully, it could be interpreted as a comment. Use a comment to login as admin without knowing the password. What is the first word on the webpage returned?

如果用户输入处理不当，可能会被解读为评论。使用评论在不知道密码的情况下以管理员身份登录。返回的网页上的第一个单词是什么？

用户名输入 admin'# ，然后密码随便输入就可以登录。

这是因为我们输入的用户名和密码会被拼接进后端的 SQL 语句中，再判断是否能对上数据库中的数据。

如果对上，就登录成功；如果用户名或密码中的任何一个没对上就登录失败。

之所以 admin'# 能登录成功，是因为后端 SQL 逻辑大致是：

1
2
3
4

SELECT * FROM users WHERE username = '$username' AND password = '$password'

# 接收我们输入的 payload 后变成
SELECT * FROM users WHERE username = 'admin'#' AND password = '$password'

' 导致提前闭合，# 注释掉了后面的密码校验。

这就导致我们成功登录了 admin。

答案：Congratulations
