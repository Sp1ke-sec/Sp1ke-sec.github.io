TwoMillion

About: TwoMillion is an Easy difficulty Linux box that was released to celebrate reaching 2 million users on HackTheBox. The box features an old version of the HackTheBox platform that includes the old hackable invite code. After hacking the invite code an account can be created on the platform. The account can be used to enumerate various API endpoints, one of which can be used to elevate the user to an Administrator. With administrative access the user can perform a command injection in the admin VPN generation endpoint thus gaining a system shell. An .env file is found to contain database credentials and owed to password re-use the attackers can login as user admin on the box. The system kernel is found to be outdated and CVE-2023-0386 can be used to gain a root shell.

介绍：TwoMillion 是一个简单难度的 Linux 靶机，是为了庆祝 HackTheBox 用户达到 200 万而发布的。盒子里装有一个旧版本的 HackTheBox 平台，其中包含旧的可破解邀请码。破解邀请码后，即可在该平台上创建帐户。该帐户可用于枚举各种 API 端点，其中一个端点可用于将用户提升为管理员。拥有管理员权限的用户可以在管理员 VPN 生成端点执行命令注入，从而获得系统 shell。发现 .env 文件包含数据库凭据，由于密码重用，攻击者可以以管理员用户身份登录到该主机。发现系统内核已过时，CVE-2023-0386 可用于获取 root shell。

靶机 IP：10.129.229.66

Task 4

The endpoint in makeInviteCode returns encrypted data. That message provides another endpoint to query. That endpoint returns a code value that is encoded with what very common binary to text encoding format. What is the name of that encoding?

makeInviteCode 端点返回加密数据。该消息提供了另一个可供查询的端点。该端点返回一个代码值，该代码值采用一种非常常见的二进制到文本编码格式进行编码。这种编码格式的名称是什么？

1
2

data: "Va beqre gb trarengr gur vaivgr pbqr, znxr n CBFG erdhrfg gb /ncv/i1/vaivgr/trarengr"
enctype: "ROT13"

加密方式是 ROT13 凯撒移位（偏移 13 位），字母循环移位 13 位。

因为字母表总共只有 26 位，所以说 ROT 13 是自逆的，也就是说加密一次=解密一次。

做 ROT 13 解密的工具有很多，这里使用 hURL：

搜索 OverlayFS，找到 CVE-2023-0386 Linux Kernel 权限提升漏洞。
