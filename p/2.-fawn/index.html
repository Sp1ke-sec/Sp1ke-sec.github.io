Fawn

About: Fawn is a very easy Linux machine which explores the File Transfer Protocol (FTP) and its exploitation when misconfigured to allow anonymous access.

介绍：Fawn 是一台非常简单的 Linux 机器，它探索了文件传输协议 (FTP) 及其在配置错误时允许匿名访问的利用方式。

靶机地址：10.129.1.14

Task 1

What does the 3-letter acronym FTP stand for?

FTP这三个字母的缩写代表什么？

文件传输协议

答案：File Transfer Protocol

Task 2

Which port does the FTP service listen on usually?

FTP 服务通常监听哪个端口？

答案：21

Task 3

FTP sends data in the clear, without any encryption. What acronym is used for a later protocol designed to provide similar functionality to FTP but securely, as an extension of the SSH protocol?

FTP以明文形式发送数据，不进行任何加密。后来出现了一种协议，旨在提供与FTP类似的功能，但更加安全，它是SSH协议的扩展，该协议的缩写是什么？

SSH File Transfer Protocol，是 SSH 的扩展，在 SSH 通道里传输文件，加密数据，替代明文 FTP。

答案：SFTP
